Como ler este documento

Tudo aqui é decisão tomada — não é exploração. Quando a interface diverge deste documento, é a interface que está errada.

O brandbook é a única fonte da verdade para a plataforma Papirando. Cada token tem um nome, um valor e um lugar pra ser usado. Se você precisa de uma cor que não está aqui, não invente: pergunte. Se a tipografia parece pequena demais, abra a seção e veja se existe um tamanho pra esse caso antes de inventar um novo.

O sistema cobre modo claro e modo escuro desde o primeiro token — não é um afterthought. Quem estuda à noite, estuda aqui também.

Cores

Papel quente + tinta + um ponto de azul

A paleta tem três famílias: superfícies (tons de papel), tinta (escala de texto) e acento (o azul de marca, usado com economia). O modo escuro inverte papel ↔ tinta mantendo a mesma temperatura quente — não vira um preto frio genérico, continua parecendo página.

Tipografia

Fraunces para o editorial · Jakarta para a UI

Duas famílias, com papéis claros. Fraunces itálico aparece sempre que há intenção editorial — títulos, números, citações, dados estatísticos. Plus Jakarta Sans faz o trabalho braçal: botões, labels, formulários, corpo de texto longo. Quando estiver na dúvida sobre qual usar, pergunte: isso é conteúdo ou é UI? Conteúdo = serifa. UI = sans.

Regra · 01
Itálico = conteúdo

O Fraunces itálico carrega a personalidade da marca. Use em títulos, números e citações — nunca em CTAs, labels de form ou texto corrido longo. Itálico em parágrafo cansa a leitura.

Regra · 02
O ponto é da marca

Títulos de tela terminam com ponto azul (.) — é a assinatura que veio do logotipo. Outros títulos (h2, h3, h4) não levam o ponto, pra não banalizar o gesto.

Regra · 03
Não invente tamanho

Se um número da escala não serve, o problema é o layout, não o tipo. O conjunto cobre todos os casos previstos. Tamanhos fora da escala quebram o ritmo vertical.

Regra · 04
Number = serifa itálica

Toda estatística da plataforma (tempo, sequência, %, contagem) usa Fraunces itálico com numerais tabulares. Isso dá personalidade aos números e mantém colunas alinhadas.

№ 03

Espaço & forma

Base 4 · raios pequenos · sombras quase só em popovers

Tudo cresce a partir de uma unidade base de 4px. Os raios são pequenos e editoriais — papel não é arredondado de mais. As sombras existem apenas quando há sobreposição real (modais, popovers, toasts). Em layout normal, bordas finas fazem o trabalho.

№ 04

Iconografia

Lucide · stroke 1.5 · grid 24px

Família única: Lucide, em stroke de 1.5px, tamanho padrão 24×24. Em UI compacta (chips, tags), reduzir pra 14–16px e aumentar o stroke pra 1.75. Cor herdada do contexto (currentColor) — quase sempre --ink-2. Ícones decorativos em --ink-3.

№ 05

Voz & léxico

Papirar / papirando como verbo do produto

Papirar é o verbo do produto. A plataforma fala como quem está estudando junto: direta, calorosa, sem formalidade desnecessária — mas sem forçar gíria onde não cabe. Pensa no monitor que você gosta: trata você por nome, conta como você está indo, te empurra de volta pro caderno quando você some.

№ 06

Ilustração

Linguagem de papel: folhas, dobras, anotações

O sistema de ilustração é uma extensão do logotipo. Todo desenho é feito de papel: folhas planas, com dobras, sombras chapadas, pequenas anotações a marca-texto. Sem gradientes complexos, sem 3D, sem personagens. Quando uma tela precisa de uma imagem, ela ganha uma cena de mesa de estudo.

Empty state · padrão

Folha em branco com canto dobrado. Para listas vazias, busca sem resultado, primeira sessão.

Conteúdo marcado

Pilha de folhas com marca-texto. Para revisão, anotações salvas, conteúdo grifado.

Sucesso · meta batida

Folha com check verde + lápis. Para acertos, conclusões, sequências mantidas.

Envio · achievement

Avião de papel. Para mensagens enviadas, badges, prêmios, conclusões de plano.

Caderno aberto

Para plano de estudos, trilha aberta, conteúdo de estudo. O destaque azul ancora o "onde você está".

Lembrete · post-it

Para notificações ativas, prazos, alertas. Usa o highlight amarelo como cor primária.

Princípios
O que toda ilustração tem em comum

Stroke preto 1.5px. Sempre. Linha consistente que amarra o sistema com a iconografia.
Sombra chapada, nunca degradê — uma cor única mais escura pra dar volume.
Marca-texto amarelo como acento secundário pode aparecer.
Sem rosto, sem mãos, sem personagens — a plataforma é sobre o conteúdo, não sobre quem está estudando.

№ 07

Movimento

Curto · funcional · nunca decorativo

Movimento serve pra guiar o olho, não pra entreter. Tudo é curto: micro-interações em 120ms, transições de painel em 240ms, no máximo 400ms. Easing padrão é ease-out (entra rápido, freia no fim) — é o que parece mais natural na maioria dos casos.

Micro · 120ms

Hover, focus, toggle. Coisa de quase invisível.

cubic-bezier(0.2, 0.8, 0.2, 1) · ease-out
Standard · 240ms

Dropdown, popover, tab change. A maioria das transições.

cubic-bezier(0.16, 1, 0.3, 1) · expo-out
Slow · 400ms

Modal, sheet, página inteira. Quando vale chamar atenção.

cubic-bezier(0.32, 0.72, 0, 1) · spring-out
